# Changelog

## 0.1.2 — 2026-11-04

- 修复 Windows 同步创建设置窗口的死锁风险，菜单入口也改为异步。
- 重做设置面板，增加动作按钮与恢复入口。
- 点击检测改用 CPU 投影轮廓，去掉同步 GPU 读回，加入 IPC 超时与恢复。
- 下半身缩短 16%，收小动作，修正头底与脸部贴合。

## 0.1.1 — 2026-11-04

- 修复交叉编译遗漏 custom-protocol，安装后错误连接 127.0.0.1:1420 的问题。
- 为 release 构建增加生产协议保护，防止再次生成依赖开发服务的包。
- 新增无需 Vite 的生产 dist 渲染与交互测试。
- 0.1.0 已确认实机启动失败，停止使用。

## 0.1.0-dev — 2026-11-04

- 初始化 `2ez4jz/Desktop-Companion` 项目，保存原始角色和三视图。
- 新建程序化 GLB 开发模型，7 个骨骼、16 个动画片段。
- 实现鼠标点击、往返抚摸、抓取、甩动、松手、弹跳、摔倒与恢复。
- 接入 6 种情绪、闲置行为和具有冷却时间的互动反馈。
- 新建 3D 调试工作室、360° 预览与持久化设置。
- 实现 Tauri 透明桌面层、全局鼠标轮询、轮廓点击穿透、系统托盘、开机启动与单实例。
- 增加 Windows 构建工作流、NSIS 配置和卸载启动项清理。
- 通过 13 项逻辑 / GLB 测试、2 项原生命中测试、10 项真实 WebGL 操作测试，以及 Windows GNU 目标编译检查。
- V1.0 仍待视觉确认、Windows 10 / 11 实机验收和真实 4 小时稳定性测试。
